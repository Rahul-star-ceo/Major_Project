# Major_Project


In today’s rapidly evolving digital landscape, cybersecurity has become a critical priority for organizations due to the increasing sophistication of cyber threats such as phishing, social engineering, data breaches, and API exploitation. With businesses relying heavily on digital infrastructure, the risks associated with poor security practices can lead to significant financial losses, compromised data, and reputational harm. Addressing these challenges requires continuous threat monitoring, proactive vulnerability assessment, and effective risk mitigation strategies.
As part of my role as a Threat Researcher at Foresiet (The Red Users), I have been actively involved in identifying, analyzing, and reporting on security risks affecting client organizations. My work focuses on three key areas: brand reputation monitoring, vulnerability assessment and penetration testing (VAPT), and API security testing.
In brand protection, I performed detailed reconnaissance to detect fake mobile applications, impostor social media accounts, and leaked credentials or API keys in public code repositories. I also monitored suspicious keyword mentions to detect reputational threats early.
For VAPT, I conducted both passive and active scans using tools such as Burp Suite, Nessus, and subdomain enumeration techniques. This included identifying exposed services, misconfigurations, and critical vulnerabilities like Insecure Direct Object References (IDOR). My assessments maintained system integrity while offering deep insights into potential exposures.
Each security issue was documented in Proof of Concept (PoC) reports, providing technical analysis, reproduction steps, and mitigation strategies. I also proposed security posture improvements to strengthen the resilience of client infrastructure.
Through this work, I have gained hands-on experience in threat research, OSINT, and vulnerability management, contributing effectively to real-world cybersecurity defense operations.
